## Cómo publicar en GitHub Pages
1. Crea un repositorio en github.com: portafolio-dcdm-2026
2. Sube todos los archivos (arrastra o usa git push)
3. Ve a Settings → Pages → Branch: main → Save
4. Tu URL será: https://tuusuario.github.io/portafolio-dcdm-2026/

## Marcadores ▼ para completar
Busca el símbolo ▼ en index.html — cada uno señala un campo que debes cambiar.
